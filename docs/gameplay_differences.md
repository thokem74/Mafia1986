# Gameplay differences

## Intentional modernizations

- One human gang, AI opponents only; no multiplayer state or hot-seat turns.
- German/English switching, large touch controls, explicit action buttons, confirmations, contextual explanations, autosave and three manual slots.
- Save active encounters, combat turns and RNG state; offline play.
- Scene-authored UI and original assets; no third-party reference assets redistributed.

## Provisional fidelity gaps (not a completed faithful release)

- Original compact Chicago district layout instead of a verified C64 map; fixed C64 roster with a selectable offer list instead of random hotel-quality offers.
- Weapon prices, precision, damage factors, prerequisites, car prices/capacity/movement, thirty recruits and friendly-shot behavior now follow fixed C64 1.20 primary data. Starting energy 5 and monthly health recovery/cap now follow C64 BASIC 313/12165/4015–4020; starting attributes use random C64 ranges rather than the original press-to-stop rolls.
- 25/50-year campaigns and 100/200-point targets retain the port configuration; original C64 timing/options require comparison.
- Rank weighting approximated using the port formula; promotion timing and some encounter/reward details require comparison.
- Safe cracking allows a qualified solo leader, resolving a conflict between C64 documentation and the Atari handler.
- AI uses deterministic pursuit with obstacle pathfinding, preserving cardinal shots and single actions while avoiding stalled port movement.

Original rules deliberately restored from primary data and port comments: remaining-step multiples of 20 with 20% police checks, five-step location visits, 1/8 monthly forgery expiry, no mayor score bonus, original gambling payout formula, original precision/strength miss check. No early-game reward boost is added.
